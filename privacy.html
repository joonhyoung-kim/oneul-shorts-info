데이터 처리 안내

개인정보처리방침

문서 작성: 2026년 11월 5일

오늘의 궁금 자동 제작은 ‘오늘의 궁금’ 채널 운영자가 자신의 채널을 운영하는 데 사용하는 개인용 데스크톱 프로그램입니다. 이 문서는 현재 프로그램과 운영 과정에서 정보를 다루는 방식을 설명합니다.

처리하는 정보와 목적

정보이용 및 보관
OAuth 인증 정보Google API 연결과 권한 갱신에 사용하는 액세스·갱신 토큰을 PC에 보관합니다. 현재 Windows 구현은 토큰을 해당 Windows 사용자 계정의 DPAPI로 암호화합니다. OAuth 클라이언트 설정도 별도 로컬 파일에 보관합니다.
채널 정보채널 ID와 이름을 읽어 업로드 대상이 운영자의 채널인지 확인하고 로컬 연결 설정에 기록합니다.
영상과 업로드 정보대본, 생성 영상, 제목·설명·공개 범위, 영상 ID와 업로드·처리 상태를 제작 및 중복 업로드 방지에 사용합니다. 파일과 작업 기록을 PC에 보관합니다.
영상별 집계 성과조회수, 참여 조회수, 시청 시간·시청 비율, 좋아요·공유, 구독자 증가 등을 읽어 성과를 검토합니다. 조회 결과를 작업 기록이나 분석 자료로 PC에 저장할 수 있습니다. 현재 분석 기능은 개별 시청자의 신원을 조회하지 않습니다.

Google·YouTube와 AI 작업환경

인증과 API 요청은 Google에 전송됩니다. 영상을 업로드하면 영상 파일, 제목·설명과 업로드 설정이 Google·YouTube에 전달됩니다. 공개 영상과 메타데이터는 지정한 공개 범위에 따라 YouTube에서 표시됩니다.

기획과 운영을 돕는 Codex 등의 AI 작업환경에서 대본, 영상 메타데이터, 집계 성과를 참조할 수 있습니다. 이 경우 해당 정보는 사용하는 AI 서비스에서 처리되므로 모든 정보가 PC 안에서만 처리되는 구조는 아닙니다. 분석 자료에는 인증 토큰이나 클라이언트 비밀값을 포함하지 않도록 운영합니다.

Google·YouTube의 데이터 처리는 Google 개인정보처리방침을 따릅니다. AI 작업환경에서 처리하는 정보에는 해당 서비스의 정책과 사용하는 계정의 설정이 적용됩니다.

보관 기간과 삭제

현재 프로그램에는 일괄 자동 삭제 기한이 설정되어 있지 않습니다. 인증 파일, 생성 영상, 업로드 기록과 저장한 분석 자료는 운영자가 관리하고 삭제합니다. PC의 백업이나 AI 작업환경에 남은 기록은 각각의 저장 위치에서 별도로 관리해야 합니다.

  1. PC의 자동 실행과 업로드 작업을 중지합니다.
  2. Google 계정의 연결된 앱 관리에서 이 앱의 액세스 권한을 삭제합니다.
  3. 운영자가 PC의 인증 파일과 필요 없는 영상·작업·분석 기록을 삭제합니다.

연결 해제와 로컬 삭제는 서로 별개입니다. Google 액세스 권한을 철회해도 기존 로컬 파일이 자동 삭제되지는 않습니다. PC에서 데이터를 삭제해도 YouTube에 이미 업로드한 영상은 삭제되지 않으며, 영상 삭제나 공개 범위 변경은 YouTube Studio에서 별도로 처리합니다.

Google의 연결 및 액세스 권한 관리 안내

이 안내 사이트

이 정적 안내 페이지에는 회원가입, 로그인, 입력 폼, 광고 또는 방문 분석 스크립트를 넣지 않았습니다. 사이트의 호스팅 제공자는 페이지 제공과 보안을 위해 IP 주소 등 접속 정보를 자체 정책에 따라 처리할 수 있습니다. 외부 링크로 이동하면 해당 사이트의 데이터 처리 방식이 적용됩니다.

운영 및 문서 관리

이 도구의 운영자와 데이터 관리 주체는 오늘의 궁금 채널 운영자입니다. 본인만 사용하는 도구이므로 데이터 확인·연결 해제·삭제는 운영자가 직접 수행합니다. 기능이나 정보 처리 방식이 달라지면 이 안내를 함께 수정합니다.
